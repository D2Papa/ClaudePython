# OEM 질의서

| 항목 | 내용 |
|---|---|
| 문서 ID | OEM-Q-001 |
| 대상 | OEM-SWR-001 OEM SW 요구사항 사양서 Rev 1.0 (BL-OEM-1.0) |
| 발신 | 공급자 SW 개발 |
| 상태 | 발송 전 (사용자 검토 필요) |

OEM 요구사항에 정의되지 않았거나 서로 충돌하는 사항입니다. 공급자는 아래 **작업 가정**으로 개발·검증을 진행했습니다. 가정과 다른 답변을 주시면 변경 요청으로 처리하고 영향받는 SW 요구사항(괄호 안 SWR)을 재검토합니다.

## 1. 안전 판단에 영향이 큰 항목 (우선 회신 요청)

| # | 질의 | 관련 OEM 요구 | 공급자 작업 가정 |
|---|---|---|---|
| Q-01 | 강제 잠금(ISOFIX)과 강제 해제(화재·과온·성인 탑승)가 동시에 성립하면 어느 쪽이 우선입니까? | FR-005, FR-006 | 충돌·화재·과온 해제 > ISOFIX·접근위험 잠금 > 성인 탑승 해제 > 자동 잠금 > 운전자 명령 (A-01) (SWR-017, 018, 022) |
| Q-02 | QM 요구 FR-003(접근위험 경고 후 재입력 override)이 ASIL B 요구 SR-002(접근위험 해제 억제)를 해제할 수 있습니까? 허용한다면 override 경로의 ASIL은? | SR-002, FR-003 | 허용하되 ASIL B로 개발 (A-02) (SWR-006) |
| Q-03 | 센서 고장(출력 유지, SR-004)과 충돌 확정(해제, SR-001)이 동시에 오면? | SR-001, SR-004 | 충돌 해제 우선 (A-03) (SWR-007, 021) |
| Q-04 | 시동 OFF가 접근위험 잠금보다 우선합니까? (안전하차보조가 시동 OFF 후에도 동작해야 하는지) | FR-007, SR-002 | 시동 OFF 최우선 (A-14) (SWR-020) |
| Q-05 | 센서 고장 중에 ISOFIX·접근위험 잠금, 성인 해제를 보류하는 것이 맞습니까? | SR-004, FR-005, FR-006 | 시동 OFF·충돌·화재·과온만 적용, 나머지는 보류하고 출력 유지 (A-18) (SWR-021) |
| Q-06 | 입력 하나만 200 ms 넘게 지연돼도 전체를 DEGRADED로 보고 잠금 판정을 보류하는 것이 맞습니까? 지연 중 출력은? | SR-003 | 전체 DEGRADED, 출력 유지 (A-12) (SWR-013) |
| Q-07 | 입력 지연·센서 고장이 생기면 성립한 override를 끝내야 합니까? | FR-003 | 보수적으로 종료, 복귀 후 재입력 필요 (A-21) (SWR-006) |
