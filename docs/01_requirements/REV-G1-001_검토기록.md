## 2. 2차 재검증 지적과 조치

| # | 심각도 | 지적 | 조치 |
|---|---|---|---|
| A | 높음 | 정지 중 성립한 override가 접근위험 유지 상태로 3.0 km/h 이상이 되어도 유지 | 3.1 순위 7a 조건에 차속 < 3.0 km/h, SWR-006-5에 "3.0 km/h 이상 시 override·t0 초기화", 수용기준 추가, A-13 갱신 |
| B | 중간 | 좌·우 결정 규칙이 다를 때 `state` 결정 규칙과 7/7a 상대 순위 없음 | 2.2에 state 우선순위 `OFF > DEGRADED > FAULT > OVERRIDE > NORMAL`, 3.1에 "7a는 7보다 높다" 명시 |
| C | 낮음 | SWR-011·014 가정 표기, SWR-005·015 추적 가정 열 누락 | 표기 추가, TRACE 정정 |
| D | 낮음 | 시동 OFF 중 지연 그룹의 state 표시, 그룹 하나 지연 시 전체 DEGRADED | 각주에 시동 OFF 시 state OFF 명시(A-14 갱신). 전체 DEGRADED는 A-12에 OEM 확인 항목으로 추가 |

재검증자는 A·B 수정 시 재검토 없이 확정 가능하다고 판정했다.

## 3. 확인된 사항 (문제 없음)

- OEM 수치 경계: 3 km/h 이상, 10 s 이하, 200 ms 초과, 100/101건, 1,000회
- 추적: OEM 요구 13/13 하향, SWR 21/21 상향, 인터페이스 9/9
- 이유 코드 정의와 3.2 매핑 일치, 이벤트 필드 11개·조회 응답 필드 9개 일치

## 4. OEM 질의 목록 (기준선 이후 처리)

개발계획서 5장 A-01~A-20 중 "OEM 확인 필요"로 표시된 항목과 A-10(SWR-019 결번)을 OEM에 일괄 질의한다. 답변이 기존 가정과 다르면 변경 요청으로 처리하고 영향받는 SWR(SWRS 5장 목록)을 재검토한다.
